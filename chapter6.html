Web Technology I

Web technology refers to the different tools, languages and technologies used to create, develop and maintain websites and web applications. The World Wide Web allows users to access information and services through the internet. Web browsers are software applications used to open and view webpages, while search engines help users find information available on the web. Web technology has become an important part of communication, education, business and entertainment.

HTML stands for HyperText Markup Language and is the basic language used to create the structure of webpages. HTML uses tags and attributes to define different elements of a webpage. The basic structure includes HTML, HEAD, TITLE and BODY tags. Heading tags from H1 to H6 are used for headings, while the paragraph tag is used to display paragraphs. Other basic tags are used for line breaks, text formatting, comments and preformatted text.

HTML provides different methods for organizing information on webpages. Ordered lists display items using numbers or letters, while unordered lists display items using different bullet styles. The address tag can be used to display contact information. Hyperlinks are created using the anchor tag and allow users to move to other webpages, documents or different locations within the same webpage. Tables can be created using tags such as TR, TH and TD to organize information into rows and columns.

HTML forms are used to collect information from users. Different form controls include text boxes, radio buttons, checkboxes, text areas and buttons. These elements are commonly used in registration forms, login forms and other webpages that require user input. HTML also supports multimedia elements such as audio and video. The source and other HTML5 elements allow media files to be included in webpages and played through compatible web browsers.

HTML5 also provides elements for creating graphics. The canvas element provides an area where graphics can be created using programming, while SVG is used for creating scalable vector graphics. Websites can also contain images, audio, video and other multimedia objects. These features make modern webpages more interactive and useful. Web hosting is the process of storing website files on a server so that users can access the website through the internet.

A domain name is the unique name or address used to identify a website on the internet. Instead of remembering a numerical IP address, users can enter a domain name into a web browser. Content Management Systems, or CMS, are software systems that allow users to create, organize and manage website content. They are useful for people who want to create websites without writing every part of the website manually.

Cascading Style Sheets, commonly known as CSS, are used to control the appearance and presentation of webpages. CSS can be applied using inline CSS, embedded CSS and external CSS. It can be used to change colours,fonts,changing colours etc.
