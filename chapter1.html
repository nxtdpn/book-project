Mainframe Computers: Large-scale systems optimized for high throughput, massive simultaneous user connections, and transaction processing (e.g., central banking, airline reservation systems). Microcomputers: Compact single-user systems powered by a microprocessor. Computer Organization: Refers to structural interconnections between hardware units that implement the architectural specifications (e.g., control signals, bus topology, hardware interfaces). 1.2.2 Components of Computer System Input Unit: Converts user data/instructions into binary signals readable by the computer. Central Processing Unit (CPU): Arithmetic Logic Unit (ALU): Performs mathematical calculations (+,−,×,÷) and logical comparisons (>,<,=)). Control Unit (CU): Directs operation flow across components by sending control timing signals. Clock Speed: The rate at which the processor executes internal operational clock cycles, measured in GHz. Word Length: The number of bits a processor can process, address, and transfer simultaneously in a single clock cycle (e.g., 32-bit vs 64-bit systems). RAM (Random Access Memory): Volatile main memory (data clears when power drops). Nepal Enotes SRAM (Static RAM): Faster, uses transistor flip-flops, does not require refreshing; used in cache. DRAM (Dynamic RAM): Uses capacitors, cheaper, requires periodic electrical refreshing; used for main system memory. ROM (Read Only Memory): Non-volatile memory storing startup instructions (BIOS/Firmware). PROM: Programmable ROM (written once). EPROM: Erasable PROM (cleared using ultraviolet light). EEPROM: Electrically Erasable PROM (flashed electrically). Cache Memory: Small, ultra-fast SRAM buffer placed between the CPU and RAM to store frequently accessed data. Nepal Enotes Buffer: Temporary memory staging area used during data transfers between hardware components running at different speeds. Nepal Enotes Magnetic Disk: Uses magnetized surfaces (platters) to write data (e.g., Hard Disk Drive - HDD). Flash Memory: Non-volatile solid-state storage without moving parts (e.g., Solid State Drives - SSD). Nepal Enotes Memory Stick: Compact flash-memory cards used in cameras and mobile handheld devices. 1.2.7 Input Devices Keyboard & Mouse: Primary alphanumeric typing and point-and-click interface devices. Scanner: Captures physical documents into digital image files. Light Pen: Photosensitive pen used directly on displays for drawing and menu selection. OMR (Optical Mark Reader): Detects shaded pencil marks on standardized answer sheets. OCR (Optical Character Reader): Scans printed text images and converts them into editable text documents. BCR (Barcode Reader): Reads printed barcode patterns to extract product data. MICR (Magnetic Ink Character Reader): Reads characters printed with magnetic ink on bank cheques. Touch Screen: Accepts user touch gestures as input directly on screen monitors. Microphone: Captures analog audio sound signals and converts them to digital format. Digital Camera: Captures visual photographs and video directly onto flash memory. 1.2.8 Output Devices Monitors: Display screen interfaces. LCD (Liquid Crystal Display): Uses liquid crystal cells backlit by CCFL lights. LED (Light Emitting Diode): Advanced display using energy-efficient LEDs for backlighting. Printers: Paper printout devices. Dot Matrix: Impact printer using pins striking an ink ribbon against paper. Inkjet: Non-impact printer spraying fine liquid ink droplets. Laser: High-speed non-impact printer using a laser beam and dry powder toner. Speaker: Outputs audio signals generated from system hardware sound cards. 1.2.9 Hardware Interfaces Parallel Port: Legacy 25-pin interface transferring multiple data bits simultaneously (historically used by printers). Nepal Enotes Serial Port: Single-bit serial interface transferring data one bit at a time sequentially. Nepal Enotes USB Ports (Universal Serial Bus): Standard plug-and-play interface providing high-speed data transfer and device power. HDMI (High-Definition Multimedia Interface): Audio/Video interface transmitting uncompressed digital video and multi-channel sound signals. Expansion Slots: System board sockets (such as PCIe slots) used to add internal expansion cards (e.g., graphics cards, sound cards, network adapters).
